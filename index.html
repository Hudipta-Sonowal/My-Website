How I Work
Leadership Philosophy
01
Build systems, not just teams
Every operation I set up is designed to outlast any one person. If the system collapses when someone leaves, it was never a system — it was a dependency. I build processes that scale independently of heroics.
02
Data first, gut second
I built 50+ dashboards not because I like dashboards — but because decisions made without visibility are guesses. Real-time data isn't a nice-to-have. It's the difference between reacting and leading.
03
Automate the repeatable, own the exceptional
If a process runs the same way more than three times, I find a way to automate it. Manual work is a tax on attention. I preserve human judgment for the decisions that actually require it.
04
Own the outcome, not just the task
I've managed budgets, vendors, agents, and engineering partnerships — because whatever it takes to move the number, I do it. I don't hand off problems. I own them through to resolution.
